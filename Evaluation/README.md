# Evaluation

This folder contains reusable ML source code:

- `inference/` — checkpoint loading and prediction.
- `preprocessing/` — validation, duplicate detection, splitting, and balancing.
- `training/` — transforms and retained training components required by inference and reproducibility.
- `evaluation/` — metrics and evaluation implementations.
- `scripts/` — curated audit, preprocessing, training, evaluation, and Grad-CAM entry points.

Raw datasets are required to rerun preprocessing, training, or full evaluation.

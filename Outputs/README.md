# Outputs

This folder contains final retained evaluation artifacts only.

- `Grape/` — metrics, classification report, and per-image predictions.
- `Tomato/` — final test summary, classification report, predictions, and misclassification metadata.

Runtime logs, temporary screenshots, build output, and generated caches are not included. New Grad-CAM results are written under `Outputs/GradCAM/` when the application runs.

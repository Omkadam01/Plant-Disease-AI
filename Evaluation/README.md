# Evaluation

This folder contains reusable ML source code:

- `inference/` — checkpoint loading and prediction.
- `models/` — EfficientNet-B0 model construction.
- `preprocessing/` — runtime transforms, dataset loading, validation, duplicate detection, splitting, and balancing.
- `evaluation/` — metrics and evaluation implementations.

Raw datasets are required to rerun preprocessing or full evaluation. Development-only training and command wrapper scripts are not retained.
